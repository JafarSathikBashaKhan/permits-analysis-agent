**Application Purchase Flow**

Step No.

Stage

Simplified Action

1

Open applicant record

Go to Users > Applicants and open the required applicant profile/application.

2

Start new purchase

Open Dispensation records and click Buy Now to start a new application.

Choose Dispensation new template permission type

3

Choose dispensation type

Select the required Dispensation permission/group from the available options.

4

Enter address details

Choose permit mode, then use a saved address or search/add an address manually.

5

Save and continue

Optionally save the address for future use, then continue to the next step.

6

Add vehicle

Select an existing vehicle or add a new vehicle for the application.

7

Add documents

Choose an existing document or upload a new document if required.

**8**

**Provide bay details**

**Enter the reason for purchase, street, bay type, and number of bays.**

**Specific to Dispensation new template**

9

Set dates and duration

Select start date/time and duration; review the calculated end date and pricing.

10

Review pricing summary

Check subtotal, admin fee, VAT/discounts, and confirm purchase details.

11

Select payment method

Choose the required payment method on the checkout step.

12

Submit application

Click Apply/Submit to complete the purchase and create the dispensation application.

13

Verify submitted record

Return to Applications/Dispensation list and verify the new application is created.
