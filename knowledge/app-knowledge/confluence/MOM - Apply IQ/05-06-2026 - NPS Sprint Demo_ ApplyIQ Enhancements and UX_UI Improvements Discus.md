## 📝 Discussion Summary:

### 1\. Dashboard & Application Status

-   Dashboard enhancement includes:
    
    -   Display of **active applications by permission types**.
        
    -   Application status tracking (expired, cancelled, renewal, rejected).
        
    -   Filtering options (Today, last 7 days, last 30 days). [\[NPS Sprint...Recording | Video\]](https://nsl365-my.sharepoint.com/personal/gokulakannan_murugesan_logicvalley_in/Documents/Recordings/NPS%20Sprint%20Demo-20260605_153153-Meeting%20Recording.mp4)
        

* * *

### 2\. Applicant Overview Enhancements

-   New additions:
    
    -   **Blue Badge and State Pension details** captured during application purchase are displayed in the overview.
        
-   Documents uploaded during purchase are currently shown in the overview section. [\[NPS Sprint...Recording | Video\]](https://nsl365-my.sharepoint.com/personal/gokulakannan_murugesan_logicvalley_in/Documents/Recordings/NPS%20Sprint%20Demo-20260605_153153-Meeting%20Recording.mp4)
    

✅ **Feedback:**

-   Overview should contain only **summary-level information**, not documents.
    
-   Documents must be moved to the **Documents section/tab**.
    
-   Display only indicators (e.g., Blue Badge = Yes + number). [\[NPS Sprint...Recording | Video\]](https://nsl365-my.sharepoint.com/personal/gokulakannan_murugesan_logicvalley_in/Documents/Recordings/NPS%20Sprint%20Demo-20260605_153153-Meeting%20Recording.mp4)
    

* * *

### 3\. Send Email Functionality

-   A **Send Email** option is available to:
    
    -   Allow back-office users to communicate with applicants.
        
    -   Use templates and maintain audit trail of communication. [\[NPS Sprint...Recording | Video\]](https://nsl365-my.sharepoint.com/personal/gokulakannan_murugesan_logicvalley_in/Documents/Recordings/NPS%20Sprint%20Demo-20260605_153153-Meeting%20Recording.mp4)
        

✅ **Feedback:**

-   Rename “Send Email” to a more user-friendly label (e.g., _Contact Applicant_).
    
-   Improve clarity on its purpose.
    

* * *

### 4\. UX/UI Observations (Critical)

Key concerns raised:

-   Lack of **information hierarchy** in the overview screen.
    
-   Excessive **white space and inefficient layout usage**.
    
-   Poor readability due to **small text size**.
    
-   Screens appear **developer-driven rather than UX-designed**.
    

✅ **Suggestions:**

-   Group related data and prioritize key fields.
    
-   Utilize full screen space effectively.
    
-   Ensure overview provides a quick summary without scrolling.
    
-   Conduct a dedicated **UX redesign discussion/workshop**. [\[NPS Sprint...Recording | Video\]](https://nsl365-my.sharepoint.com/personal/gokulakannan_murugesan_logicvalley_in/Documents/Recordings/NPS%20Sprint%20Demo-20260605_153153-Meeting%20Recording.mp4)
    

* * *

### 5\. Car Park Management Feature

-   Introduced **“Manage Car Park” toggle**:
    
    -   Enables/disables map integration.
        
-   Car park configuration includes:
    
    -   Name, location, type, total spaces, classification, status.
        
    -   Map-based location pinning.
        
    -   Additional features (EV charging, disabled bays, etc.). [\[NPS Sprint...Recording | Video\]](https://nsl365-my.sharepoint.com/personal/gokulakannan_murugesan_logicvalley_in/Documents/Recordings/NPS%20Sprint%20Demo-20260605_153153-Meeting%20Recording.mp4)
        

✅ **Feedback:**

-   Default classification inconsistency identified.
    
-   Suggested defaulting classification to **Off-street**.
    
-   Postcode input to enforce correct format.
    
-   Consider integration with **address lookup APIs**.
    

* * *

### 6\. Seasonal Car Park (Permit Builder)

-   New **Seasonal Car Park category** under non-zonal permits.
    
-   Includes:
    
    -   Car park mapping to permissions.
        
    -   Pricing configuration (duration-based).
        
    -   Discount handling (e.g., Blue Badge).
        
-   Aligns with existing permit configuration. [\[NPS Sprint...Recording | Video\]](https://nsl365-my.sharepoint.com/personal/gokulakannan_murugesan_logicvalley_in/Documents/Recordings/NPS%20Sprint%20Demo-20260605_153153-Meeting%20Recording.mp4)
    

* * *

### 7\. Customer Journey – Car Park Search

-   Users can search via:
    
    -   Car park name
        
    -   Postcode/address
        
-   Results shown in:
    
    -   Map with location pins
        
    -   List view with pricing and details
        

✅ **Feedback:**

-   Current pricing display via modal is confusing.
    
-   Suggest:
    
    -   Showing pricing directly in card/expandable section
        
    -   Reducing unnecessary clicks and pop-ups
        
-   Loading concerns discussed but challenged.
    

* * *

## 📌 Key Decisions:

-   Move documents out of overview into Documents tab.
    
-   Redesign overview layout with better UX principles.
    
-   Rename “Send Email” functionality.
    
-   Proceed with UX review session for ApplyIQ screens.
