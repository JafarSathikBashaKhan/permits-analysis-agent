## Acceptance Criteria

Given a Super Admin or Contract Admin** 
When in the Permission Builder
 
Then the system should display a ‘Permission Label’ section. 

 
Text Editor:**** 
When the user selects ‘Permission Label’
 
Then a text editor should be available to configure the label text.
 
The label context should be displayed in the application form for the permission. Refer [#169081](https://dev.azure.com/MHPortfolio/Permits/_workitems/edit/169081/) 

 
Text Formatting:** 
When the user selects text and applies formatting options 
Then the text should reflect the chosen style, including: 

- Bold, Italic, Underline 
- Font size and font style 
- Alignment (left, center, right) 
- Ordered and unordered lists 
- Hyperlinks 
 
 
**Content Editing:** 
When the user performs editing actions such as Cut, Copy, Paste, Undo, Redo 
Then the editor should update the content accordingly while maintaining formatting.
