## Acceptance Criteria

Given as a super admin/ contract admin
 
 
 
When in the applicant detail view screen
 
Then the user should see the Overview tab with the following data listed: 

- Title 
- First Name 
- Last Name 
- Date of Birth - (Empty for now until Experian Api integration) 
- Mobile number 
- Email 
- Blue badge number 
- Home address 
- Business address 
 
When any of the field doesn't have data, 
Then the field can be empty. (Eg: Blue badge number) 
 

 
When in the view screen, 
Then should see the name and the title of the user in the top. (Ref Figma)
