## Acceptance Criteria

Given a Super Admin or Contract Admin, 
When configuring a permission / rules / application form and attempting to navigate away from the screen (e.g., by clicking on a menu item or button that leads to a different page) before saving changes, 
Then the user should see a confirmation message:
"You have unsaved changes. Would you like to save your work as a draft before leaving?" 
With options as: 
Stay On Page - When invoked, the pop up should be closed and should stay in same page  
Don't Save - When invoked, should let the user navigate to the desired page without saving any changes made. 
Save and Leave - When invoked, should save the changes made and navigate user to the desired page.
