## Acceptance Criteria

Given a Super admin / Contract admin user, 
When in the 'Users' menu of Apply system, 
Then should see a sub menu named 'System users'. 

 
**System Users List** 
When in the system users sub menu, 
Then should see the list of users or user accounts created in MNPS system who are mapped with relevant Apply contract. 
 
Note: 

- Only the user accounts of user roles applicable in Apply system should be shown here. 
 
 
When in the system users list screen, 
Then should see the user details segregated in the column as "First Name, Last Name, Role, Email Address, Contact Number". 

 
**Pagination** 
When in the list screen, 
Then the pagination should be there. 

 
**Column Level Sorting and Filtering** 
When interacting with list, 
Then should have default column level sorting and filtering. 

 
~~**Import**~~ 
~~When want to import the user list,~~ 
~~Then should be able to import as CSV by selecting appropriate button in the UI.~~ 

 
**Status Column** 
When in the list screen, 
Then should see the status of users as 'Active or Deactivated' based on the actual status.
