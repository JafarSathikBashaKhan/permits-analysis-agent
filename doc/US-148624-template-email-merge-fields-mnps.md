## Acceptance Criteria

**Given** a Super Admin or Contract Admin
**When** in the text editor
**Then** the user should have the option to Insert Merge Fields. 
**When** the option is invoked
**Then** a predefined list of merge field values should be available in a dropdown with a search function(Single select).
(The list of merge fields is provided in the attachment section.) 
**When** the user places a placeholder in the text editor
**And** invokes the Insert Merge Fields option to select a merge field
**Then** the selected merge field should be inserted into the placeholder. 
**When** a merge field is placed
**Then** it should not be editable the only available action is to remove the merge field.
