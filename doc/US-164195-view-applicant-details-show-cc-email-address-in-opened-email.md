## Acceptance Criteria

Display of CC Field
 
Given a Super Admin / Contract Admin / BO Manager / BO User, 
When an email has CC recipients,  
Then "CC:" field must be shown below the "To" field.
 

 
When no CC exists,  
Then CC field should be hidden.
 

 
**Multiple CC Recipients**
 
When multiple CC recipients exist,  
Then all addresses should be shown separated by commas (or line breaks for readability).
 

 
**Formatting Consistency**
 
When viewing, 
Then CC field must align with the format of the To/From fields.
