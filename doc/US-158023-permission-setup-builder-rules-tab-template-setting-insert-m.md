## Acceptance Criteria

**** 
**Given** a Super Admin or Contract Admin****When** in the text editor
**Then** the user should have the option to **Insert Merge Fields **in physical permission template and white mail reminder** **. 
**When** the Insert Merge Fields option is invoked
**Then** a predefined list of merge field values (as provided in [#148624](https://dev.azure.com/MHPortfolio/Permits/_workitems/edit/148624/) ) should be available in a **dropdown with a search function** (single select). 
 
 
 
 
 
 
 
 
Note:** Merge field list attached in the attachment section 
 
 
 
 
 
 
 
 
 
 
 
 
**When** the user places a placeholder in the text editor
**And** invokes the Insert Merge Fields option to select a merge field
**Then** the selected merge field should be inserted into the placeholder. 
**When** a merge field is placed
**Then** it should be **non-editable**, and the only available action should be to **remove** the merge field.
