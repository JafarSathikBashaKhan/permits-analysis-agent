## Acceptance Criteria

**Upload Documents for Personal Vehicle** 
Given a Super Admin / Contract Admin / BO Manager / BO User, 
When adds personal vehicle, 
Then uploading a document of proof becomes mandatory. 

 
When want to upload document proof, 
Then should see the provision to upload the document. 
(Should select the document types before uploading. - drop-down) 
Note:
 All the documents submitted here will be treated as proof of vehicle 
ownership. Their sub categories should be shown in the drop-down. 

 
When uploads document, 
Then should
 be able to upload the document in .png, .pdf, .jpg, .bmp, .tif, .heic 
and max size 10 mb. (The same indication should be shown in UI) 
Note: Maximum 10 documents should be allowed per vehicle. (Same should be indicated in UI for users as info text) 

 
When uploaded the document, 
Then should also have the provision to delete or remove the document. 

 
When want to add a new personal vehicle, 
Then except the field to mark as registered keeper, all other fields are mandatory fields. 

 
When filled all the mandatory fields, 
Then should be able to add the vehicle with appropriate button click. 

 
When want to delete the documents, 
Then there should be provision to delete.
