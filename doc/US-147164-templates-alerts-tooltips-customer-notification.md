## Acceptance Criteria

Given a super admin/contract admin 
 
When in the customer notification section 
Then should have the  

- Text editor - Text Editor should accept maximum of 200 characters 
- Customer Notification - Toggle 
 
When enter the message in the text editor 
Then should enable the 'Customer Notification' toggle enable 
** 
Text Formatting** 
When the user selects text and applies formatting options,** 
Then the text should reflect the chosen style (bold, italic, underline, font size/style, alignment, lists, hyperlinks). 
 
 
 
Content Editing** 
When the user performs editing actions (cut, copy, paste, undo, redo),** 
Then the editor should update the content accordingly and maintain formatting. 
 

 
** 
 
**Edit Existing Notification** 
When wants to update the message 
Then the Customer Notification section opens in edit mode with the current message pre-filled 
 
** 
Save & Cancel** 
 
When invoke the button to save 
Then the changes are saved and reflected on the login screen 
 
** 
 
 
When invoke button to cancel, 
Then no changes are saved and the previous alert configuration remains unchanged. 

 
Reference** 
When want to notify the customer about the application changes 
Then should use this 'Customer Notification' 
** 
When the 'Customer Notification' is enable 
Then the Banner** should appear in the customer portal login page with the option to close 
** 
When the 'Customer Notification' is disabled 
Then should not appear in the customer portal login page
