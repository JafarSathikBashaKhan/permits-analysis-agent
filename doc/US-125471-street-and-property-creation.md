## Acceptance Criteria

Given I'm a super admin or Contract admin 
When invokes "New Street" from street grid screen 
Then should get displayed with data fields that assist in
creating streets and Properties. 
  
When trying to create a street 
Then should have the following fields available, 
  
**Street name** 
- should be a free text, alphanumeric field, accepts
character limitation up to 100 and a mandatory field, duplicates are allowed. 
  
**USRN** 
- works based on the toggle at the contract settings,  
- if the toggle is enabled then this field should
auto-generate the USRN number. 
- If the toggle is off, then this field should be a free
text, alpha numeric field with character limitation up to 15 characters. 
- The value entered and autogenerated based on the toggle
should be unique across each streets, No duplicates to be entertained 
- Throw error message when identified duplicate USRN as
"Duplicate USRN." 
- Ref story for USRN and UPRN toggle field. [[User
Story 129426](https://dev.azure.com/MHPortfolio/Permits/_workitems/edit/129426): USRN and UPRN toggle settings] 
  
**Town ** 
- should be a Mandatory drop down field, should be able
to type in and select the town 
- Town should be mapped against the street created. 
  
**Add properties/ Buildings Name & No** 
- should be a Mandatory field 
- Should be a free text alpha numeric field 
- Should be able to type in, and enter the property names /
number [Type in and tap on enter to add the entry] 
- Should be validated for uniqueness with in the street its
mapped to. 
-Against each property added, there should be an option to
remove it.  
-If the properties are exceeding the space, then enable scroller 
 
- should be validated for duplication.  
** 
UPRN** 
- works based on the toggle at the contract settings, if the
toggle is enabled then this field should auto-generate the UPRN number. 
- If the toggle is off, then this field should act as an
free text, alpha numeric field with character limitation up to 15 characters. 
- This value entered and autogenerated based on the toggle
should be unique across each streets, No duplicates to be entertained 
- Throw error message when identified duplicate UPRN as
"Duplicate UPRN." 
- Ref story for USRN and UPRN toggle field. [[User
Story 129426](https://dev.azure.com/MHPortfolio/Permits/_workitems/edit/129426): USRN and UPRN toggle settings] 
  
**Post Code** 
- Accepts alpha numeric includes spaces, should have
character limitation up to 15 characters 
- should be a Mandatory selection field 
- If the typed in postcode is already available in the
system against a contract then the suggestion should be shown in the field drop
down for easy selection. 
  
**Permission Limit**** ** 
- should be a numeric field which ideally accepts count of
permit that can be applied against the property [Increment and decrement values via + & -] 
- Should accepts value range from 0 to the max of 99. 
  
When all the required fields has been populated 
Then should see two action button as "Cancel" and
"Add Street". 
  
When all the required fields has been populated 
Then should see  "Add Street" being in
enabled by default 
AND 
Invoking which should have the entry added to DB and list
out the entry in the street grid screen. 
  
When invoked on **Cancel**, 
A confirmation prompt should appear with the message: 
"Are you sure you want to cancel, as this will reset
the data on the screen and close it?" 
with 
Yes and No button, 
Yes should clear the values and close the pop and navigates
to list screen. 
AND 
No will retain in the add street screen. 
**
 
When in add street screen  
Then should see the count of properties added against the
street.  
  
Events**: **Street Creation** 
Event name: Street creation 
Event Description: Street, Property, Town and Postcode
created and associated 
Date and Time stamp: Current date and time 
User Role: $Role of the user who made the change 
User Name: First Name and Last Name of the user who done the
change. 
  
Error validation: 
All the fields are mandatory. 
When a field is left empty, throw error message as
"This field is required." 
USRN & UPRN duplicate validation should be available,
with error message as "Duplicate USRN/UPRN."  
  
**Note:** 

 - When
     a street is created, multiple properties can be created and mapped against
     it 

 - Town
     is associated with street name 

 - Postcode
     is associated with Property 

 - A
     property cannot be mapped to multiple street, single mapping should be
     allowed. 

 - USRN
     is a unique identifier of street 

 - UPRN
     is a unique identifier of property 

 - Streets
     created will be associated to zone and these address will be used to apply
     for a permissions.
