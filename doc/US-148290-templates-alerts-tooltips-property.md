## Acceptance Criteria

Given a super admin/contract admin 
 
When in the 'Property' tab 
Then should have the  

- Address 
 
Fields with Text box should accept maximum of 500 characters 
 
 
 
 
** 
Edit ** 
When wants to update the tooltip 
Then the property section opens in edit mode with the current message pre-filled 
 
** 
Save & Cancel** 
 
When invoke the button to save 
Then the changes should saved  
** 
 
 
When invoke button to cancel, 
Then no changes are saved and the previous alert configuration remains unchanged. 
 
 

** 
**Reference** 
When in the application form Address field,   
Then should see a help icon (e.g., an “i” icon) next to that field 
 
When the user hovers over the help icon 
Then a tooltip should appear showing the configured help message
