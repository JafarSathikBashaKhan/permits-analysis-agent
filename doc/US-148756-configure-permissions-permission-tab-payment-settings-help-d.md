## Acceptance Criteria

**Permission Setup > Builder > [Permission Name] > Permission Tab > Payment Settings** 
**
** 
Given a super admin/contract admin 
When in the payment settings  
Then they should see: 

- Online Payment Methods – with a list of checkboxes. 
- Offline Payment Methods – with a list of checkboxes. 
 
 
& 
A **Payment Method Help Description** –  Text box should accept maximum of 500 characters. 
** 
Reference:** 
 
When in the application form **Payment Methods **field
 
Then they should see a help icon (e.g., an “i” icon) next to that field 

 
When the user hovers over the help icon
 
Then a tooltip should appear showing the configured help message
