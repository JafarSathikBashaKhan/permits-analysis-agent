Search: 
Given a Super admin / Contract admin, 
When in the System User list Screen, 
Then should be able to type and search the First Name, Last Name, Email Address 
 
When typed in the search bar, 
Then should see the the matching user in the list. 
 
When cleared the search bar, 
Then should see the full list of system user displayed again.
