## Acceptance Criteria

**Given** a Super Admin, 
**When** viewing the Notification Template dropdown,**Then** the below option should be available in the list.
 

- Set password success 
- Password change success 
- Send visitor voucher 
- Application put on hold 
- Application resumed 
- Application reactivated 
- Application reinstate 
- Internal referral 
 
And the existing 'Reset Password' should be renamed as 'Forgot Password' 
And 'Reset Link' should be renamed as 'Resend Confirmation Link'
