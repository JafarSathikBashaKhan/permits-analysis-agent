## Acceptance Criteria

**Search ****Vehicles**
 
When there are multiple vehicles,
 
Then should be able to search for the "VRM, Nick Name 'Make, Model and Color'" in the search box. 
 
& 
When searched in the search box, 
Then based on the availability the results should be filtered in the grid. 

 
When typed the full word and triggered an event (Could be invoking search button or enter), 
Then post the event trigger results should be filtered down. 

 
When applied filter for visitors vehicle, 
Then the favorite one should be on the top. 
 

 
**Filter** 
When want to filter the vehicles, 
Then should be able to filter the vehicles based on types. (Eg: Personal, Visitors)
