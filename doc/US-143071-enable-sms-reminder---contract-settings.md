## Acceptance Criteria

Given a Super admin and Contract admin user, 
When in the Contract settings screen, 
Then should find a toggle setting named "SMS Reminder" in others section. 

 
When want to enable the SMS reminder, 
Then should be able turn on the toggle. 

 
When want to disable the SMS reminder, 
Then should be able turn off the toggle. 

 
When enabled,  
Then should see the confirmation pop-up as "Enabling this will activate the SMS reminder feature for this contract. Are you sure you want to enable it?" 

 
When disabled,  
Then should see the confirmation pop-up as "Disabling this will activate the SMS reminder feature for this contract. Are you sure you want to enable it?"
