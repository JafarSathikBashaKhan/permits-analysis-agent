## Acceptance Criteria

**Display of Vehicle Field Toggles
** 
 
Given a Super Admin or Contract Admin is viewing the Contract Settings page,
 
When they navigate to the Vehicle Field Configuration section,
 
Then all configurable vehicle fields that are listed below should be there with toggle options. 

 
Vehicle type
 
Fuel Type
Make
 
Model
 
Color
 
CO₂ Emission (g/km)
 
Euro Standard 
Type of engine
 
Engine size
 
Age of the vehicle
 
Number Plate Tax Band 
Number of Seats
 
When in the vehicle field configuration section, 
Then should be able to enable or disable the toggle. 

 
When configuring the vehicle fields, 
Then all the fields are non-mandatory.
