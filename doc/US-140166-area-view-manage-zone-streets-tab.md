## Acceptance Criteria

**Given a Super admin / Contract admin
When in the zone list screen
Then should see the zone name invokable.

On invoking the respective zone entry in the grid screen
Then should be taken to view zone screen with two tabs

- Streets
- Permissions


And by default, it is opened with streets tab
Then should display the following details with view access



**
**Street Tab**
When in the street tab
Then should see the below two fields

- Street name - Should display the street name that mapped against this zone
- No of property - Should display the number of properties that is mapped against each street.

Note: This Mapped Street and properties happened in Street creation.
**
Column Filter, Sorting** & **Paging**



****


Default column filter, sorting & pagination is applied.
**
Global Search**
When in the search field,
Then should be able to search street name

When enter street name in the streets tab,
Then system should display the matching name on the street tab.
