## Acceptance Criteria

Edit Blue badge 
If the blue badge number and proof evidence is added in the applicant account 
When want to edit  
Then should see the button to edit blue badge in the overview 
 
When invoke the button to edit the blue badge 
Then should be able to edit the blue badge number and proof of evidence 

 
When in the edit screen 
 
If two files have already been uploaded
 
Then should display the indication in the upload option "File limit reached. Remove a file to upload a new one." 

 
If the file limit is not reached
 
Then the user should be able to upload additional files. 
 
 
 
When the changes are made 
Then should be able to invoke the button to save changes 

 
If both the documents and blue badge numbers are removed 
Then the button to save the changes should be disabled 
 
Remove Document 
 
 
When the user chooses to remove an added document
 
Then the document should be removed from the record. 

 
When a document is removed
 
Then the user should again be able to upload a new document. 

 
When the document is updated in the Applicant BO against the applicant account (and vice versa)
 
Then the same document should also be available in the Customer Portal.
