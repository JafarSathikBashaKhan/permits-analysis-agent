## Acceptance Criteria

**Search**: 
Given a Super admin / Org admin / Contract admin, 
When in the Roles and Permissions list Screen, 
Then should be able to type and search the user role. 

 
When typed a role name in the search bar, 
 
Then should see the the matching roles in the list. 

 
When cleared the search bar, 
Then should see the full list of roles displayed again.
