## Acceptance Criteria

**** 
**** 
**Current State of Application : Pending-Approval** 
**Application enters Pending Approval after submission at Customer portal** 
Given the applicant has completed and submitted the application form from customer portal 
And all mandatory fields and required documents are provided 
When the system validates the application successfully 
Then the application status must change to "**Pending Approval**" 

 

 
 
** ** 
**BO User manages an application in Pending Approval status (Possible Actions of BO)**  
Given the application is in "Pending Approval" status 
Then BO user should be able to see "Begin Review" Button in respective Permission application to start review the application  
And Application status must change to "**In-Progress"** 

 

 

 
 

  
**Updated Application status must change to "**In-Progress"** **
