## Acceptance Criteria

**Navigation**

 Given the Permissions details page

When the user selects a Reference Number

Then the system must open the Application View screen for that reference number

And navigate to **Documents** section

**Access Documents tab**

  Given the Application View screen is open

  When the user selects the Documents tab

  Then the system must display the list of documents linked to the application

**View documents uploaded via Citizen Portal**

  Given the Application View screen is open

  And the Documents tab is selected

  When documents have been uploaded by the applicant via the Customer/Citizen Portal

  Then the system must display all such documents related to the application
