## Acceptance Criteria

**Navigation - Permission tab - > Zone mapping - > Edit Pricing Button
** 
 
** 
When there are more than one pricing configuration available against a permission
 
Then should see a drop down available to select a pricing scheme available.
 
And
 
User should select one from the list and should proceed invoking the "Edit Pricing" button to edit the pricing.
 

 

 
Navigation - Permission tab - > General Settings 
** 
** 
When in general settings, 
 
Then have the "Permit related to" field removed
 

 
When in Zone mapping section while creating a zone set
 
Then all the zone created against the contract to be available in the drop down for selection.
 

 
Change Zone Limit** 
When the permission group is zonal 
Then in the general settings section 'Change Zone Limit' field should be shown 

 
When the permission group is non zonal 
Then in the general settings section 'Change Zone Limit' field should be hidden
