## Acceptance Criteria

Given a Super admin and Contract admin, 
When in the Permissions setup -> Rules, 
Then should see a sub menu named "Auto Approval Settings". 

 
When in the auto approval settings, 
Then should see the below mentioned set of static auto approval options with check box or toggle, 

- Auto Approval on Renewal 
- Auto Approval on New Applications 
- Auto Approval on Change Number Plate Request 
- Auto Approval Visitors Permissions 
 
When viewing the check boxes, 
Then should see the following help texts. 

- Auto Approval on Renewal - Automatically approve user-submitted renewal requests for this permission. 
- Auto Approval on New Applications - Automatically approve newly submitted applications under this permission. 
- Auto Approval on Change Number Plate Request - Automatically approve requests to update vehicle registration numbers. 
- Auto Approval Visitor and Visitor Scratch Card Permissions - Automatically approve visitor and scratch card applications under this permission if the user has an active resident permit already. 
 
 

 
When in the section, 
 
Then should be able to allow or disallow auto approvals by adjusting the check boxes or toggles. 
& 
Then the check boxes are non-mandatory for both saving as draft and publishing.
